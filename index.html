Conectar Wallet (NWC)
Para usar HDMP v2, necesitás conectar tu wallet via Nostr Wallet Connect (NIP-47). Esto permite crear invoices, verificar pagos automáticamente y registrar Zaps.
¿Cómo obtengo mi NWC string?
1. Andá a getalby.com o tu wallet NWC compatible
2. Settings → Nostr Wallet Connect
3. Create new connection (con permisos: make_invoice, lookup_invoice, get_balance, list_transactions)
4. Copiá el string que empieza con nostr+walletconnect://
